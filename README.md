# 📚 Online Book Store Website

A modern, responsive e-commerce web application for an online book store. Built using **HTML5**, **CSS3**, and **JavaScript**, this project provides a multi-page interface for browsing books, managing a shopping cart, creating user accounts, and processing orders.
